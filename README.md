# LLM Patterns

## 한국어

이 스킬은 LLM을 처음 접했거나 아직 익숙하지 않은 사용자가 모델의 낯선 행동을 이해하도록 돕습니다. 지침을 무시하는 것처럼 보이거나, 사용자의 의도와 다른 방향에 고착되거나, 같은 실수를 반복하는 이유를 패턴으로 진단합니다.

목적은 LLM의 사전 경향(prior), 관성, 습관을 설명하는 데 있으며, 모델의 행동을 직접 교정하거나 변화시키지는 않습니다.

- 한국어 스킬: `llm-patterns-ko`
- 영어 스킬: `llm-patterns`

```bash
npx skills add babyfings/llm-patterns
```

## English

This skill helps people who are new to or unfamiliar with LLMs understand puzzling model behavior. It diagnoses patterns behind behavior such as appearing to ignore instructions, becoming fixated on a direction that differs from the user's intent, or repeating the same mistakes.

Its purpose is to explain an LLM's priors, inertia, and habits. It does not directly correct or change the model's behavior.

- Korean skill: `llm-patterns-ko`
- English skill: `llm-patterns`

```bash
npx skills add babyfings/llm-patterns
```
